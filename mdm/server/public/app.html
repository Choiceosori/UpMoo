'우리반 수업' 앱 설치 (안드로이드 태블릿)

앱으로 들어오면 새 창도 앱 안의 탭으로 열리고, 선생님이 학생 화면을 보고 탭을 닫을 수 있어요.

QR로 설치

태블릿 카메라로 찍으면 설치 파일을 내려받아요.

설치 파일 내려받기

설치 순서

  1. 내려받은 woori-class.apk를 열어요.
  2. '출처를 알 수 없는 앱' 경고가 뜨면 설정 → 이 출처 허용 → 뒤로 와서 설치.
  3. 앱을 열고 서버 주소(처음 한 번)와 방 코드, 번호를 넣어요.
  4. 수업에 들어오면 '앱 고정'을 물어요. 확인을 눌러요.
  5. 선생님이 화면을 볼 때 "녹화 또는 전송을 시작할까요?"가 뜨면 시작.
학교 관리자에게 설치 파일은 서버의 public/app/woori-class.apk에 두면 이 페이지에서 내려받을 수 있어요. 빌드 방법과 기기를 관리자 모드(Device Owner)로 설정하는 방법은 저장소의 mdm/README.md를 봐 주세요. 관리자 모드로 설정하면 확인 없이 앱이 고정되고, 학생이 앱을 지우거나 안전모드로 우회할 수 없어요.

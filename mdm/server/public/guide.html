우리반 수업도우미 사용 안내

학생 태블릿과 선생님 화면을 하나로 묶어, 활동지·화이트보드·에듀테크 링크·퀴즈를 한 곳에서 보내고 살펴봐요.

차례 처음 수업 5단계 학생 들어오기 활동지·내 판서 화이트보드 링크 보내기 수업 자료 미리 넣기 로그인 필요한 사이트 학생 찾아보기 학생 앱(탭 통제) 학생 보기·통제 화면 공유 모둠 활동 퀴즈 제목·수업 끝내기 활용 기록·돌아보기 관리자 자주 묻는 질문 학생용 안내

처음 수업 5단계

  1. 로그인선생님 화면에서 구글로 로그인해요. 처음이면 사용 신청을 보내요.
  2. 반 고르기맡은 반 카드를 눌러요. 반이 하나면 바로 열려요.
  3. 새 수업새 수업에서 제목·활동지·화이트보드를 고르고 시작해요.
  4. 학생 입장TV에 QR을 띄우면 학생이 찍고 번호를 골라 들어와요.
  5. 수업하고 끝내기활동지·링크·퀴즈를 보내고, 마치면 수업 끝내기.

학생 들어오기

학생은 로그인하지 않아요. 방 코드 4자리와 자기 번호만 있으면 돼요.

  1. 선생님 화면 위쪽 방 코드를 누르면 TV에 QR과 코드가 크게 떠요.
  2. 학생은 태블릿 카메라로 QR을 찍거나, 인터넷 주소에 들어가 숫자판으로 방 코드를 눌러요.
  3. 자기 번호를 누르고 네, 들어갈래요를 누르면 끝이에요.
  4. 모두 들어왔으면 위쪽 입장 잠그기를 눌러요. 방 코드를 아는 다른 반 학생이나 바깥 사람이 빈 번호로 들어올 수 없어요. 이미 들어온 태블릿은 연결이 끊겨도 다시 들어와요. 누가 들어오려 하면 선생님 화면에 알림이 떠요.
처음 한 번: 학생 수와 이름표 왼쪽 반 설정에서 마지막 번호를 맞추고 이름을 넣어요. 전출 등으로 빈 번호는 해당 번호의 체크를 꺼 주세요. 마지막 번호 24번에서 22번을 제외하면 23명이고 23·24번은 그대로 들어와요. 기존 활동 기록은 남으며, 체크를 다시 켜면 복원돼요. 엑셀의 번호 없는 이름 목록은 사용 중인 번호만 차례로 채워져요. 이름은 이 기기에만 저장되고 서버로 가지 않아요.

활동지·내 판서

  • 활동지 올리기로 PDF나 사진을 고르면 학생 화면에 바로 나타나요. 여러 쪽 PDF도 쪽마다 나뉘어요.
  • 아래쪽 ‹ 1 / 3 ›으로 선생님 쪽을 넘겨요(키보드 ← →도 돼요).
  • 따라오기를 켜면 학생 화면이 선생님이 보는 쪽을 따라와요. 끄면 학생이 자유롭게 넘겨요.
  • 왼쪽 내 판서에서 쓰면 학생 화면 활동지 위에도 바로 보여요. 학생 필기는 학생 자기 화면과 선생님 화면에만 보여요.

화이트보드

활동지 없이 빈 판에 바로 쓰고 싶을 때 써요.

  1. 아래쪽 화이트보드를 누르고 흰 판·모눈·줄 공책 가운데 골라요.
  2. '학생 화면도 이 쪽으로 데려오기'를 켜 두면 학생 태블릿도 그 쪽으로 넘어와요.
  3. 선생님은 내 판서에서 쓰고, 학생은 자기 태블릿에 써요. 학생 필기는 학생 보기에서 한눈에 봐요.
새 수업을 화이트보드로 시작하기 새 수업 창의 '화이트보드'에서 판을 고르면 수업이 빈 판 한 쪽으로 시작해요. 모둠이 한 판에 함께 쓰는 판은 모둠 활동에 있어요.

링크 보내기 (패들렛·경북AI배움터 등)

다른 에듀테크 사이트를 학생 태블릿에 바로 열고, 선생님이 다시 불러들여요.

  1. 아래쪽 링크 보내기를 눌러 주소를 붙여 넣어요.
  2. 잠깐 뒤에 '앱 안에서 열 수 있어요' 같은 안내와 학생 화면 미리 보기가 떠요. 서버가 그 사이트의 설정을 확인해서 여는 방법을 저절로 골라요.
  3. '학생에게 보일 이름'을 확인하고 지금 학생에게 보내기.
  4. 활동이 끝나면 같은 창의 모두 돌아오기를 눌러요. 학생 화면이 수업 화면으로 돌아오고, 학생이 이 화면에서 연 새 창도 닫혀요(브라우저가 막아 둔 경우에는 닫히지 않고 알림으로 불러요).

앱 안에서 열기 (추천)

사이트가 학생의 우리반 화면 안에 열려요. 학생이 우리반 화면을 떠나지 않아서 모두 멈춤과 모두 돌아오기가 바로 먹히고, 카드에 '링크 보는 중'이 떠요.

  • 경북AI배움터(로그인은 새 창)
  • 패들렛
  • 유튜브
  • 카훗
  • 멘티미터
  • 웨이그라운드
  • 젭
  • 엔트리
  • 미리캔버스
  • 위키백과

새 창으로 열기

다른 화면 안에 넣지 못하게 막아 둔 곳이나, 앱 안에서는 로그인이 풀리는 곳에 써요. 학생 태블릿에 '열기' 단추가 뜨고, 학생이 누르면 새 창으로 가요. 카드에는 '링크로 나감'(하늘색)이 떠서 딴짓(빨간색)과 구분돼요.

  • 구글 클래스룸
  • 캔바
  • 스크래치
  • 알로
  • 투닝
  • 띵커벨
  • 클래스카드

사이트 목록은 2026년 9월에 확인한 결과예요. 사이트 사정에 따라 바뀔 수 있으니, 보내기 전 미리 보기로 확인하는 것이 가장 정확해요. 미리 보기가 회색이거나 오류가 뜨면 '새 창으로 열기'를 골라요.

패들렛·유튜브는 주소만 넣으면 돼요

패들렛 보드 주소와 유튜브 영상 주소는 앱 안에 넣는 전용 주소로 저절로 바뀌어요. 유튜브 주소에 시작 시각(t=)이 있으면 그 시각부터 재생돼요.

새 창으로 간 학생 부르기

학생 화면 위쪽 알림 켜기를 한 번 눌러 '허용'하면, 선생님이 모두 돌아오기나 모두 멈춤을 누를 때 학생 기기에 "선생님이 불러요" 알림이 떠요. 알림을 누르면 수업 화면으로 돌아와요. 우리반 화면이 열린 브라우저 탭이 살아 있을 때만 알림이 가요(탭을 닫으면 안 와요).

할 수 없는 것 웹 주소로 쓰면 다른 앱이나 다른 탭의 화면을 볼 수 없어요. 그래서 학생이 새 창에서 무엇을 쓰는지는 이 화면에 나오지 않아요. 학생 결과물은 패들렛·클래스룸 같은 그 서비스의 선생님 화면에서 확인해 주세요. 되도록 '앱 안에서 열기'를 쓰거나, 학생 태블릿에 우리반 수업 앱을 설치하면 학생이 딴 데로 가는 것을 가장 잘 막을 수 있어요.

한 번 보낸 링크는 링크 창 아래 '최근에 보낸 링크'에 남아서, 다음 수업에 눌러서 바로 다시 보낼 수 있어요.

수업 자료 미리 넣기(링크 쪽)

활동지·화이트보드·링크를 수업 순서대로 미리 넣어 두면, 쪽을 넘기기만 해도 학생 화면에 그 자료가 열려요.

  1. 링크 창에서 주소를 넣고 수업 자료에 쪽으로 넣기를 누르면 자료 끝에 링크 쪽이 생겨요.
  2. 아래쪽 쪽 번호(2 / 5)를 누르면 수업 자료 창이 열려요. ↑↓로 순서를 바꾸고, 휴지통으로 지워요. 활동지·화이트보드·링크 쪽도 여기서 더해요.
  3. 수업 중 선생님이 링크 쪽으로 가고 따라오기가 켜져 있으면 학생 화면에도 그 사이트가 열려요. 따라오기를 끄면 학생이 쪽을 넘기며 스스로 자료를 열어요.
  4. 선생님 내 판서에서 링크 쪽을 보면 그 사이트가 선생님 화면에 미리 보이고, 연 학생 수가 나와요.
지난 수업 자료 다시 쓰기 새 수업 창의 '지난 수업 자료 불러오기'에서 고르거나, 수업 자료 창의 지난 수업에서 가져오기를 누르면 활동지·화이트보드·링크 쪽이 그대로 들어와요. 맡은 다른 반의 수업에서도 가져올 수 있어요(학생 필기는 옮기지 않아요).

로그인이 필요한 사이트(경북AI배움터 등)

경북AI배움터 같은 곳은 앱 안에서 열 수 있지만, 로그인만은 앱 안에서 할 수 없는 경우가 많아요.

로그인 서버가 보안 쿠키(SameSite=Lax)를 쓰면, 브라우저는 이 쿠키를 다른 사이트 화면 안에서는 저장하지 않아서 앱 안에서 로그인하면 "로그인 세션이 만료되었습니다"가 떠요. 이 화면만의 문제가 아니라 어느 서비스에 넣어도 같아요.

  1. 링크를 보낼 때 '로그인이 필요해요'를 켜요(관리자가 등록해 둔 사이트는 저절로 켜져요).
  2. 학생 화면 링크 위쪽에 새 창에서 로그인이 떠요. 학생이 눌러 새 창에서 로그인해요.
  3. 로그인한 뒤 그 창을 닫거나 우리반 화면으로 돌아오면, 앱 안의 사이트가 로그인된 채로 다시 열려요.
이렇게 하면 안 돼요 크롬 시크릿 모드와 삼성 인터넷(기본으로 다른 사이트 안의 쿠키를 막음)에서는 로그인한 뒤에도 앱 안에서는 로그인이 풀려요. 학생 태블릿은 일반 크롬을 쓰거나, 그 링크는 '새 창으로 열기'로 보내요. 학생도 링크 위쪽 '안 되면 새 창으로'를 눌러 바로 새 창에서 할 수 있어요.

학생 스스로 찾아보기

학생이 새 탭을 몰래 열지 않고, 이 화면 안에서 검색하고 사이트를 열게 해요.

  1. 위쪽 학생 찾아보기 허용을 누르면 학생 화면 위에 찾아보기가 생겨요.
  2. 학생은 검색어(구글 안전 검색)나 사이트 주소를 넣어 화면 안의 탭(3개까지)에서 봐요. 선생님이 넣어 둔 링크 쪽도 바로 열 수 있어요.
  3. 앱 안에 넣지 못하게 막은 사이트는 '안 되면 새 창으로'를 눌러요. 이렇게 연 새 창은 '앱 벗어남'으로 세지 않아요.
  4. 학생이 연 곳과 검색어는 카드에 "찾아보기: …"로 보이고, 카드를 크게 보면 오른쪽에 마지막으로 찾아본 곳이 나와요. 수업 기록에는 이번 수업에서 찾아본 곳이 모두 남아요. 다시 누르면 꺼져요.

검색 결과에서 누른 사이트가 화면 안에서 막혀 있으면 빈 화면이나 오류가 보일 수 있어요. 그때는 '안 되면 새 창으로'를 눌러요.

학생 앱 '우리반 수업'(탭까지 통제)

웹 주소로 쓰면 학생이 크롬의 다른 탭으로 가는 것을 막을 수 없어요. 학생 안드로이드 태블릿(갤럭시탭 등)에 앱을 설치하면 모든 창이 앱 안의 탭으로 열려요.

  • 새 탭도 앱 안에서: 선생님 링크의 '새 창', 학생 찾아보기의 '새 창'처럼 사이트가 여는 새 창까지 모두 앱 위쪽 탭으로 열려요. 크롬으로 나가지 않아요.
  • 탭이 보여요: 학생 카드에 앱 · 탭 2, "탭: 리딩앤"처럼 지금 보는 탭이 보이고, 크게 보기에 열린 탭 목록과 연 주소가 나와요.
  • 학생 화면 보기: 위쪽 학생 화면 보기를 켜면 앱 학생의 화면이 4초마다 카드에 작게 보여요(저장 안 함, 학생 태블릿에 표시가 떠요).
  • 실시간 화면(발표 수업): 위쪽 실시간 화면에서 학생을 최대 6명 골라 화면을 크게 봐요. 앱 학생 태블릿에 "녹화 또는 전송을 시작할까요?"가 뜨면 학생이 시작을 눌러요. 그림으로 이어서 보여요(한 명이면 초당 8장, 6명이면 한 명당 3장 정도). 화면 오른쪽 위에 '그림 · 초당 n장'이 보여요. 한 화면을 누르면 그 학생만 크게 보여요. 학생 카드를 크게 본 뒤 실시간으로 크게를 눌러도 돼요.
  • 모두에게 보여 주기: 실시간 화면의 학생 화면 아래 모두에게 보여 주기를 누르면 그 학생 화면이 반 모두의 태블릿에 떠요(발표하는 학생 자신은 그대로 활동). 끝낼 때는 같은 단추(보여 주기 끝내기)나 위쪽 '○번 화면을 모두에게 보여 주는 중'을 눌러요.
  • 통제: 모두 멈춤은 탭 위까지 덮고, 모두 돌아오기는 탭을 모두 닫아요. 한 학생만은 크게 보기의 앱 탭 모두 닫기.
  • 로그인: 사이트가 탭 그대로 열려서 앱 안 화면에서 막히던 로그인도 앱 탭에서는 돼요.
  • 구글 로그인 탭: 구글은 앱 안 화면에서의 로그인을 막아 두었어요. 그래서 구글 클래스룸처럼 구글 로그인이 필요하면 앱이 구글 로그인 탭(크롬 탭)을 열어요. 선생님 카드에는 "탭: 구글 로그인 탭"이 보이지만 그 탭 안의 주소는 선생님 화면에 나오지 않아요.
  • 앱 고정: 수업에 들어오면 앱이 '앱 고정'을 요청해요. 학교가 기기를 관리자 모드(Device Owner)로 설정해 두면 확인 없이 고정되고, 홈·최근 앱 단추와 알림창도 막혀요.

학생 앱 설치 방법 보기 (TV에 띄우고 학생이 QR을 찍어 설치해요)

아이패드는 앱이 없어서 웹 주소로 써요(앱 안 탭·학생 화면 보기는 안 돼요).

학생 보기·통제

왼쪽 학생 보기에서 모든 학생 화면을 카드로 한눈에 봐요.

카드 모습뜻
초록 점수업 화면을 보고 있어요.
빨간 테두리가 깜빡임 · '앱 벗어남'다른 앱·탭으로 갔어요. 옆의 '이탈 n'은 이번 수업에서 벗어난 횟수예요.
하늘색 · '링크 보는 중' / '링크로 나감' / '링크 활동 · 확인 필요'선생님이 보낸 링크와 관련된 상태예요. '확인 필요'는 링크를 보던 중 화면이 가려졌다는 신호일 뿐, 새 탭을 열었거나 딴짓했다는 뜻이 아니에요. 실제 활동은 학생이 허용한 화면 공유로 확인해요.
흐린 카드 · '안 들어옴' / '연결 끊김'아직 안 들어왔거나 인터넷이 끊겼어요. 다시 연결되면 저절로 돌아와요.
  • 카드를 누르면 그 학생 화면을 크게 봐요. 다른 쪽도 넘겨 볼 수 있어요.
  • 위쪽 거르기(접속 링크 앱 벗어남 안 들어옴)로 필요한 학생만 모아 봐요. 카드 크기는 오른쪽 작게·보통·크게.
  • 모두 멈춤: 학생 화면을 덮고 "선생님을 봐 주세요"를 띄워요. 링크를 보는 중에도 덮여요. 다시 누르면 풀려요.
  • 학생이 번호를 잘못 골랐으면 그 카드를 크게 본 뒤 자리 비우기를 눌러요. 학생은 번호를 다시 골라요.

화면 공유

선생님 컴퓨터 화면을 학생 태블릿에 띄워요.

  1. 맥이나 윈도우의 크롬·엣지·웨일에서 화면 공유를 눌러요.
  2. 공유할 탭·창·전체 화면을 골라요. 화면은 그림으로 0.3초마다 보내져요(소리는 가지 않아요).
  3. 끝낼 때는 같은 자리의 공유 끝내기.
알아 두면 좋아요 아이패드는 브라우저가 화면 공유를 막아서 할 수 없어요. 영상의 소리까지 들려주려면 TV 스피커로 틀어 주세요.

학생 화면을 반 모두에게(발표)

앱이나 노트북으로 들어온 학생의 화면은 실시간 화면에서 모두에게 보여 주기를 누르면 다른 학생 태블릿에 떠요. 선생님 화면 공유와 같은 자리에 "○번 친구 화면"으로 보이고, 선생님이 화면을 공유하던 중이면 그 공유는 멈춰요.

모둠 활동

  1. 왼쪽 모둠 → 모둠 나누기에서 모둠 수를 정하고 번호 순서대로 또는 골고루 섞어요.
  2. 모둠 활동 시작에서 판 바탕(빈 판·모눈·활동지 한 쪽)을 골라요. 학생 태블릿이 모둠 판으로 바뀌어요.
  3. 같은 모둠 친구들이 한 판에 함께 쓰고 메모를 붙여요. 선생님은 모둠 카드를 눌러 크게 보고, 함께 쓰거나 이 모둠 멈춤을 해요.
  4. 산출물 그림으로 저장으로 모둠 판을 그림 파일로 받고, 모둠 활동 끝내기로 마쳐요.

퀴즈

  1. 왼쪽 퀴즈 → 새 퀴즈 만들기. 객관식·O·X·단답형·서술형을 섞을 수 있어요. 만든 퀴즈는 모든 반이 함께 써요.
  2. 퀴즈 옆 보내기에서 결과를 바로 보여 줄지, 선생님이 결과 보내기를 누를 때 보여 줄지 골라요.
  3. 현황판에서 제출 수·평균·문제별 정답률·안 낸 학생을 실시간으로 봐요. 객관식·O·X·단답형은 저절로 채점돼요.
  4. 단답형에서 맞게 봐 줄 답은 정답 인정, 서술형은 점수를 직접 줘요. 마치면 퀴즈 끝내기.
성취도 변화 보기 같은 퀴즈를 단원 처음과 끝에 보내고 지난 퀴즈 결과를 보면 점수 변화(▲%p)가 나와요. 학생별 점수 CSV로 엑셀에서 볼 수 있어요.

수업 제목 바꾸기·수업 끝내기

수업 제목 바꾸기

위쪽 '지금 수업' 제목( 표시)을 누르면 바꿀 수 있어요. 활용 기록에 이 제목으로 남아요.

수업 끝내기

  1. 위쪽 수업 끝내기를 눌러요.
  2. 학생 태블릿은 "수업이 끝났어요. 수고했어요!"로 바뀌고, 이 방 코드로는 더 들어올 수 없어요. 보낸 링크와 화면 공유도 닫혀요.
  3. 선생님 화면에는 참여 학생 수·수업 시간·보낸 활동이 정리되어 나와요. 학생 필기와 퀴즈 결과는 그대로 남아서 계속 볼 수 있어요.
  4. 다음 시간에는 새 수업 시작. 새 방 코드가 생겨요.

수업을 끝내지 않고 바로 새 수업을 시작해도 괜찮아요. 다만 '수업 시간(분)'은 수업 끝내기를 누른 수업만 기록돼요.

활용 기록·수업 돌아보기

왼쪽 활용 기록에 수업마다 참여 학생, 수업 시간, 활동지 쪽수, 학생 필기, 따라오기·모두 멈춤·앱 벗어남 감지, 화면 공유, 링크 보냄·링크 연 학생, 모둠 활동, 퀴즈 보냄이 쌓여요. 엑셀(CSV)로 받아 결과보고서의 "솔루션 활용 횟수·기능별 활용 빈도"에 써요.

관리자는 반 고르기 화면의 모든 반 활용 기록 CSV로 모든 반 기록을 한 파일로 받아요.

수업 돌아보기와 피드백

  1. 활용 기록 표에서 수업 한 줄을 누르면 그 수업의 학생 활동이 열려요: 들어온 시각, 필기 양, 앱 벗어남, 링크 연 횟수, 찾아보기, 모둠 메모, 퀴즈 점수.
  2. 표의 피드백 칸에 쓰면 바로 저장돼요. 학생 번호를 누르면 그 학생이 쓴 것과 찾아본 곳을 크게 보며 피드백을 써요.
  3. 학생 화면·모둠 판에서 그날 필기와 모둠 산출물을 다시 봐요. CSV로 학생별 활동과 피드백을 한 파일로 받아요.
  4. 이 자료로 새 수업을 누르면 그 수업 자료로 바로 새 수업을 시작해요.

관리자 (반 만들기·선생님 받기)

  • 반 고르기 화면 아래 관리에서 반을 만들고, 반마다 담당 선생님을 체크해요.
  • 선생님 받기: 처음 쓰는 선생님이 구글로 로그인하면 사용 신청 양식이 떠요. 관리 화면 위쪽에 「사용 신청 n건」이 뜨면, 우리 학교 선생님인지 확인하고 맡을 반을 골라 승인하거나 거절해요. 승인 전에는 아무것도 볼 수 없어요.
  • 이메일을 알면 '로그인할 수 있는 선생님'에 바로 등록해도 돼요.
  • 구글 로그인을 설정하기 전에는 서버의 관리자 비밀번호로 들어가요.

자주 묻는 질문

학생 태블릿에서 다른 앱으로 한 작업을 볼 수 있나요?

노트북 크롬·엣지에서는 학생이 화면 공유를 허용하면 볼 수 있어요. 선생님이 실시간 화면에서 학생을 고르고, 학생이 화면 선택·공유를 눌러 허용해요. 전체 화면을 고르면 그 화면에서 다른 탭·프로그램으로 옮겨도 보이고, 탭을 고르면 그 탭만 보여요. 안드로이드 앱 학생은 '학생 화면 보기'와 '실시간 화면'으로 태블릿 화면 전체가 보여요.

경북AI배움터를 앱 안에서 열었는데 로그인이 안 돼요.

로그인 서버의 보안 설정 때문에 로그인만은 앱 안에서 할 수 없어요. 학생이 링크 위쪽 새 창에서 로그인을 눌러 로그인하고 돌아오면 앱 안에서 이어서 해요. 시크릿 모드·삼성 인터넷에서는 이 방법도 안 되니 '새 창으로 열기'를 써요. 자세한 것은 로그인이 필요한 사이트.

링크 활동 중인데 화면 확인이 필요하다고 나와요.

다른 사이트의 링크 창에 초점이 갔는지, 다른 탭으로 옮겼는지를 브라우저 신호만으로 확정할 수 없어요. 새 탭으로 이동했다고 단정하지 않고 확인이 필요한 상태로 표시해요. 학생이 허용한 화면 공유로 현재 활동을 확인해 주세요.

실시간 화면이 '화면 녹화를 허용하는 중…'에서 멈춰 있어요.

학생 태블릿에 뜬 "녹화 또는 전송을 시작할까요?" 창에서 시작을 눌러야 화면이 와요. 안드로이드가 앱을 켤 때마다 한 번씩 물어요. 학생이 취소했으면 실시간 화면을 끝냈다가 다시 열어요.

실시간 화면은 데이터를 얼마나 쓰나요?

화면은 학교 와이파이 안에서 이 서버를 거쳐 그림(JPEG)으로 오가요. 학생 화면 보기는 4초에 한 장, 작은 크기라 반 전체여도 부담이 적어요. 실시간 화면은 한 명이면 초당 8장 정도라 와이파이가 느리면 장수가 줄어요. 대신 늘 가장 최근 화면이 가도록 밀린 그림은 버려요. 반 모두에게 보여 줄 때는 와이파이가 막히지 않게 0.4초에 한 장씩 보내요.

구글 클래스룸(구글 로그인)이 앱에서 안 열려요.

앱 안 화면에서는 구글이 로그인을 막아 두었어요. 우리반 수업 앱은 구글 로그인이 필요하면 저절로 구글 로그인 탭(크롬 탭)을 열어요. 그 안에서 로그인하고 쓰면 돼요. 태블릿에서 크롬을 처음 열면 '크롬에 오신 것을 환영합니다'가 한 번 뜨는데, 계정 없이 사용을 누르면 돼요.

자료와 기록은 어디에 저장되나요?

이 프로그램을 설치한 학교 서버의 data 폴더에 저장돼요. 반마다 수업·활동지 그림·필기·링크·퀴즈 답안·활용 기록·피드백이 들어 있고, 선생님 명단·반 목록·퀴즈 모음은 따로 있어요. 학생은 번호로만 저장되고 이름은 선생님 기기에만 있어요. 반을 지우면 그 반의 기록도 모두 지워져요. 얼마나 썼는지는 관리자 화면의 저장 공간 → 확인하기에서 봐요.

"이미 다른 기기가 이 번호로 들어와 있어요"가 떠요.

학생이 번호를 잘못 골랐거나 기기를 바꾼 경우예요. 학생 보기에서 그 번호 카드를 눌러 자리 비우기를 누르면 다시 고를 수 있어요.

링크를 앱 안에서 열었는데 회색 화면이 나오거나 로그인이 계속 풀려요.

그 사이트가 다른 화면 안에서 열리는 것을 막았거나, 앱 안에서는 로그인을 유지하지 않는 경우예요. 모두 돌아오기 뒤 '새 창으로 열기'로 다시 보내요. 학생도 링크 위쪽 '안 되면 새 창으로'를 눌러 바로 열 수 있어요.

새 창으로 간 학생에게 알림이 안 와요.

학생 기기에서 알림 켜기를 눌러 '허용'해야 해요. 이미 '차단'을 눌렀다면 브라우저 설정 → 사이트 설정 → 알림에서 이 사이트를 허용해 주세요. 우리반 화면 탭을 닫았거나 기기가 절전 상태면 알림이 오지 않거나 늦을 수 있어요. 휴대폰·태블릿 크롬은 웹 알림을 막는 경우가 많아서, 태블릿은 우리반 수업 앱을 권해요.

아이패드에서 화면 공유가 안 돼요.

아이패드 브라우저가 화면 공유를 막아 두었어요. 맥이나 윈도우 컴퓨터의 크롬·엣지·웨일에서 해 주세요. 아이패드로는 판서·학생 보기·퀴즈는 모두 돼요.

인터넷이 잠깐 끊기면 학생 필기는 어떻게 되나요?

다시 연결되면 저절로 이어서 들어와요. 학생 화면 위쪽 점이 초록이면 연결된 상태예요. 끊긴 동안 쓴 획은 화면에는 남지만 선생님에게는 가지 않을 수 있어요.

학생 이름이 서버에 저장되나요?

아니요. 서버에는 번호만 있어요. 이름표는 선생님이 넣은 그 기기(브라우저)에만 저장돼요. 다른 기기에서는 이름표를 다시 넣어야 해요.

학생용 안내 (TV에 띄우거나 읽어 주세요)

  1. 태블릿 카메라로 TV의 QR을 찍어요. (또는 주소에 들어가 방 코드 4자리를 눌러요)
  2. 내 번호를 누르고 네, 들어갈래요.
  3. 선생님이 보낸 활동지에 펜으로 써요. 쓴 것은 선생님 화면에 바로 보여요.
  4. 선생님이 링크를 보내면 그 화면에서 활동해요. '열기' 단추가 뜨면 눌러요. '새 창에서 로그인'이 보이면 눌러서 로그인하고 이 화면으로 돌아와요.
  5. 선생님이 '찾아보기'를 열어 주면 여기서 검색해요. 내가 찾아본 곳은 선생님 화면에 보여요.
  6. 위쪽 🔔 알림 켜기가 보이면 한 번 눌러 '허용'해요.
  7. 수업 중에는 다른 앱으로 가지 않아요. 선생님 화면에 바로 보여요!
